# Task bw-29 (Blocksworld, difficulty: hard)

Domain rules:
- Blocks are either on the table or stacked on exactly one other block.
- The robot arm can hold at most one block at a time.
- Actions:
    * pickup(X)    -- requires X on table, X clear, arm empty
    * putdown(X)   -- requires arm holding X
    * stack(X, Y)  -- requires arm holding X, Y clear
    * unstack(X, Y)-- requires X on Y, X clear, arm empty

Blocks: a, b, c, d, e, f, g, h

Initial state:
- Block a is on the table.
- Block c is on the table.
- Block e is on the table.
- Block g is on the table.
- Block b is on top of block a.
- Block d is on top of block c.
- Block f is on top of block e.
- Block h is on top of block g.
- Block b is clear (nothing on top).
- Block d is clear (nothing on top).
- Block f is clear (nothing on top).
- Block h is clear (nothing on top).
- The robot arm is empty.

Goal state:
- Block h is on the table.
- Block a is on top of block b.
- Block b is on top of block c.
- Block c is on top of block d.
- Block d is on top of block e.
- Block e is on top of block f.
- Block f is on top of block g.
- Block g is on top of block h.

Output a plan that achieves the goal, using EXACTLY this format:
PLAN:
1. <action>
2. <action>
...

Each <action> must be one of: pickup(X), putdown(X), stack(X, Y), unstack(X, Y).
Do not output anything before 'PLAN:' or after the last numbered line.
